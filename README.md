# 工作室財務健康 APP v4 — 更新與部署說明

## 這次改了什麼

### 名稱與密碼
- 「迪特軍EV」「電動車」全部改成 **電車男電能車**。舊資料在讀取時會自動換成新名稱，不必手動改。
- 預設密碼改成 **053005**。
- 「設定」頁可以直接修改密碼。新密碼存在 Apps Script 的 Script Properties 裡，不會寫在程式碼中。
- 忘記密碼時，到 Apps Script 編輯器執行 `resetPasswordToDefault`，密碼就會恢復成 053005。

### 介面重新設計
- **手機底部導覽列**：總覽／帳本／＋記帳／未收付／設定，中間的「＋」是記帳快捷鍵。
- **月份切換**：用 ‹ › 切換上、下個月，桌機版另有「本月」按鈕。
- **記帳更快**：金額放最上面、字放大；業務和分類改成點選按鈕（不用再開下拉選單）；客戶名稱會自動提示以前填過的；帳戶、專案、備註收在「更多欄位」裡。
- 記完一筆**會留在記帳頁**，方便連續記帳。系統會記住上次選的業務、收支類型和帳戶，右邊（手機在下方）會列出最近記的帳。
- 金額欄按 Enter 就能直接儲存。
- **帳本**依日期分組，並顯示每天的淨額和篩選結果的收入／支出合計。點任一筆就能修改；可**匯出 CSV**（Excel 可直接開啟）。
- **未收未付**：待收、待付分開列出，最久的排在最前面，並標示已經拖了幾天（超過 30 天會變紅）。每筆都有 **「標記已收／已付」一鍵按鈕**。
- **「記住我」**：勾選後，這台裝置下次打開就會自動登入。
- 支援**深色模式**（跟著手機或電腦的設定切換）。

### 儀表板
- 本月淨利放大顯示，並附上**與上月比較**的增減。
- **損益兩平進度條**：顯示本月還差多少營收才能打平；有設定老闆月薪的話，也會顯示含月薪還差多少。
- **本月支出結構**：列出前 6 大支出分類。
- 健康燈號旁邊會用一句話說明原因。

### 計算與穩定性修正
- **「個人」收支不再算進工作室數字**。舊版會把個人吃飯等支出一起算進工作室損益，現在只顯示在「個人」卡片上。想改回舊算法，把 `.gs` 裡的 `INCLUDE_PERSONAL_IN_STUDIO` 改成 `true` 即可。
- **現金續航**改用近 3 個月的平均燒錢速度計算，不會因為單一月份忽高忽低而大幅跳動。
- 舊版「老闆月薪目標」有設定欄位，卻沒有用在任何計算上，現在已接進損益兩平。
- 「未收未付」的筆數改為真實總數，舊版最多只會算到 30 筆。
- **寫入時加鎖**：兩台裝置同時記帳時，資料不會互相覆蓋。
- **防公式注入**：說明欄輸入 `=`、`+`、`-`、`@` 開頭的文字，試算表會當成一般文字，不會當成公式執行。
- 固定成本可以**刪除**了（舊版只能新增）。
- 找資料列改用 TextFinder，資料量變大後修改、刪除也不會變慢。
- 登入時直接載入資料，從兩次連線減為一次，開啟速度更快。
- 網路逾時（30 秒）與連線失敗時會顯示清楚的提示；按下儲存後按鈕會暫時停用，避免連點造成重複記帳。

## 部署步驟

### 1. 後端 `.gs`
1. 打開 Google 試算表，點「擴充功能」→「Apps Script」。
2. 全選現有程式碼並刪除，貼上 `Code.gs` 的內容，然後存檔。
3. 在上方的函式下拉選單選 **`upgradeToV4`**，按「執行」▶️。這一步會把試算表裡的舊名稱改寫成「電車男電能車」；不執行其實也能用，但執行後試算表會比較整齊。
4. 點「部署」→「管理部署作業」→ 編輯（鉛筆圖示）→ 版本選「**新版本**」→ 部署。
   網址不會改變，仍然是原本的 `.../exec`。

> v3 已經搬移過舊資料，**不要再執行** `migrateOldLedgersToTransactions`，否則資料會重複。

### 2. 前端 `index.html`
把 `index.html` 上傳到 GitHub Pages，覆蓋原本的檔案。API 網址已經填好，不用修改。

### 3. 測試
1. 打開網頁，輸入 053005 登入。
2. 確認總覽頁的業務卡片出現「電車男電能車」。
3. 記一筆測試帳，再到帳本點它，確認可以修改和刪除。

## 小提醒
- 已經列在「固定成本」的項目（例如店租），平常就不要再記成支出，否則會重複扣。
- 業務分類清單在 `.gs` 最上方的 `CATEGORIES`，想新增分類就改那裡，改完要重新部署新版本。
